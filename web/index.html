ปุ่ม “ถอดรหัสเต็ม” ใช้ได้เมื่อรัน node server.js บนเครื่อง/VPS แล้วเปิดหน้านี้ผ่านเซิร์ฟเวอร์นั้น บน GitHub Pages จะใช้ได้เฉพาะ Detect

2) ผลลัพธ์

ยังไม่ได้รัน

ใช้งานบน Termux (แนะนำสำหรับมือถือ)

pkg update -y
pkg install -y git nodejs python curl
git clone https://github.com/yooohubyooodev-serverscript/yoohubdeobfbyfox.git
cd yoohubdeobfbyfox
bash install-termux.sh

# ถอดรหัส
node deob.js script.lua
node deob.js script.lua -o out.lua
node deob.js script.lua --detect
node deob.js script.lua --no-devirt

รันเว็บ + API บนเครื่องตัวเอง

npm install
node server.js
# เปิด http://localhost:3847

เซิร์ฟเวอร์จะเสิร์ฟหน้าเว็บนี้และรับ POST /api/deobf เพื่อรัน engine จริง
